# VSCGE engine SDK

Genre-neutral, headless turn-based sessions with typed game definitions, atomic Redux-backed transitions, JSON snapshots, native presentation contracts, and optional ASCII-grid helpers.

The package exports `GameSession`, `GameDefinition`, `Presentation`, validation helpers, and the versioned `VscgeApi` contract. It does not import VS Code or impose RPG entities. See the repository's `docs/creating-a-game.md` and demo for authoring examples.

Build with `npm run build -w @vscge/engine` and package with `npm run package` from the repository root. No open-source license has been selected.
