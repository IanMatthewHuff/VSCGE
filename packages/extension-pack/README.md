# VSCGE Starter Pack

Installs the VSCGE core host and its movement/combat dungeon demo together.

An extension pack references separately published Marketplace IDs; it does not contain those extensions' code. For local development before publication, install the core and demo VSIX files individually. `vscge-dev` is a development publisher placeholder.

Both runtime extensions support native VS Code desktop/web surfaces. No open-source license has been selected.
