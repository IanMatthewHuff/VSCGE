# VSCGE Dungeon Demo

A small independently implemented dungeon game inspired by VSCDC2's native IDE approach. Requires the VSCGE core extension.

Run **VSCGE: Start Dungeon Demo**, or choose Dungeon Demo through **VSCGE: Start Game**. WASD moves one cell or attacks a goblin on an adjacent cell. Each accepted action also resolves enemy responses. Defeat both goblins to win; restart after victory or defeat.

Arrows/mouse inspect cells without advancing time. Details and actions appear in the dedicated VSCGE sidebar, which opens alongside the VSCGE game log when a game starts. Keyboard focus stays in the game editor for immediate play. VSCGE commands save/load one slot per workspace.

This demo intentionally excludes inventory, equipment, leveling, NPCs, and procedural generation. VSCDC2 source was not copied or modified. No open-source license has been selected.
